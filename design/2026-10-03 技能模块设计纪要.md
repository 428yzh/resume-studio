## 一、已定结论

### 定位

| # | 结论 |
|---|---|
| 1 | 技能库 = **技能监测平台（探测仪）**，不是学习平台。放弃「一站式学习」 |
| 2 | 三条硬约束让它打不过网课平台：权威性 / 动手环境 / 反馈闭环 / 注意力时长 |
| 3 | 真实需求是三个**自我评估**痛点：我到底会不会 · 理解有没有漏洞 · 学到什么程度算够。三者共同点是**都不需要更多内容** |
| 4 | 三件套角色：AI 讲解 = 输入（给一个**待验证**的框架）· 康奈尔笔记 = 加工 · 费曼 = 验证 |
| 5 | 核心风险是 AI 内容制造**流畅性错觉** —— 写得越顺，错觉越强。三件套的价值在打破它 |

### 分数机制（本次定稿）

| # | 结论 |
|---|---|
| 6 | 技能的掌握程度**不是一个数字，是一张图上的分布** |
| 7 | **图谱是技能级的**，AI 生成一次。网状、可多层，节点是**概括级条目**（「工具的实现方式」），不是具体问题 |
| 8 | **图谱先生成，学习计划根据图谱生成** ← 顺序确定，`generate_learning_plan` 的输入要改 |
| 9 | AI 用提示词把图谱**切分成学习步骤**（一个单元 = 图谱的一块），这同时是学习步骤的来源 |
| 10 | 每个单元的概述展开它分到的那块，并**往下再拆一层** |
| 11 | 用单元知识点 + 图谱结构**生成问题** |
| 12 | 判卷 → 分数加在**下层知识点**上 → **自下而上累加**（上层分由下层汇总） |
| 13 | **图谱是严格的树，不是网（DAG）**。累加规则本身要求树 —— 交叉引用会导致父节点重复计数 |
| 14 | 树的容量写进**图谱生成 prompt 的硬约束**：层数 ≤3、顶层 4-6 个、每个 3-5 个（约 20-30 节点） |
| 15 | **分数和覆盖率必须成对显示**（`分数 100 · 已验证 12%`）。只显示分数就是更漂亮的假分数 |
| 16 | 图谱**要展示出来**（技能工作台的主体） |

### 自评与验证

| # | 结论 |
|---|---|
| 17 | `proficiency` 现有四个写入点，**两个是假的**：新建表单预填 50（= 没表态）、JD 导入写 0（= 从没问过） |
| 18 | `proficiency` 应允许 `NULL`，语义 = 未表态；**「未验证」是一等状态** |
| 19 | 状态四态：**未验证 / 高估 / 对得上 / 低估**。仪表盘只排前两个（高估要处理、未验证要行动；低估是安慰不是动作） |
| 20 | 自评不该是入口，该是**下注**（预测—揭晓，POE / 元认知校准）。0–100 滑块对新手无可回答性 |
| 21 | 落差 = 自评 − min(证据)。**每个探测器只能证伪，不能证实** |
| 22 | 置信度分层：客观判分 1.0 > AI 判定 0.8 > 笔记启发式 0.4 > 自评 0.2 |

### 页面与入口

| # | 结论 |
|---|---|
| 23 | 技能库从「**表格**」改为「**卡片/仪表盘**」—— 表格回答"有哪些技能"，卡片回答"我的图谱长什么样、哪块虚" |
| 24 | 页面三层：`/skills`（技能卡片）→ `/skills/:id` **技能工作台**（图谱主体，新增）→ 单元学习面板 |
| 25 | **单元学习面板保持页内面板，不拆独立路由** |
| 26 | 四个探测器的入口要**反转**：从技能详情发起、带 `skill_id` 走，而不是先去那个板块 |

### 复盘（原「AI 判卷」）

| # | 结论 |
|---|---|
| 27 | **改名** —— 不是判分，是让 AI 看你的答案、理解你的思路、指出思维模式上的不足 |
| 28 | 展示改**抽屉式**（不需要 SSE 改造，一次性渲染进去即可） |
| 29 | 顺序**不硬性要求**，页面流程上提示"可以复盘了"就行（符合 PRODUCT.md 原则 4：不替用户做决定） |

### 数据与工程

| # | 结论 |
|---|---|
| 30 | **localStorage → 服务端迁移**。必需：`cornell__{skillId}__step{n}`（笔记原文）、`explain_topics__*`（知识点关键词） |
| 31 | **明确不做向量数据库** —— 单用户 / 13 技能 / 几十条笔记，SQLite FTS5 或 `LIKE` 够用 |
| 32 | 不造「上下文管理系统」抽象，照 `quiz.py::_skill_context()` 按需拼字符串 |
| 33 | **新老并存** —— 老的 13 个技能 / 9 个旧学习计划不迁移、不管，用新的做测试 |
