# 简历亮点盘点（按功能板块）

> 用途：简历与面试素材主文档。每条均为仓库真实实现，附出处便于面试展开。
> 用法：投不同岗位挑不同板块组合；简历放 3-5 条，其余留作面试弹药。

## 1. 简历编辑与导出

- 【工程】表单通用化：一套 `SectionForm` 驱动全部 8 种区块类型（single/array 双模式 × 6 种字段类型），新增区块类型只扩配置不改组件
- 【工程】PDF 中文乱码根因修复：默认 Helvetica 单字节字体把中文字符码点截断为低字节（"中文测试" → `-‡KÕ`），不报错不警告；定位根因后注册 NotoSansSC 字体子集，修复全部历史导出（简历 + 试题两类 PDF 共用）
- 【产品】PDF 导入 → AI 解析成结构化区块，旧格式自动迁移，用户无感
- 【UI】三栏编辑器布局（编辑区 2/3 + 侧栏 1/3），区块完成度可视化

## 2. AI 润色

- 【工程】SSE 流式逐 token 渲染，AbortController 随时取消（POST + fetch ReadableStream，非 EventSource——后者只支持 GET）
- 【产品】三个润色目标分层：语法修正 / STAR 法则重构经历 / ATS 关键词增强
- 【工程】AI fallback 降级：模型不可用时返回原文不阻断主流程

## 3. JD 分析

- 【产品】四路采集入口覆盖求职者真实场景：粘贴文本 / 图片 OCR / 链接抓取 / 自研 BOSS 直聘 Chrome 扩展（manifest v3）
- 【产品】全链路闭环：JD 解析 → 技术栈自动导入技能库 → 简历匹配度差距分析 → JD 专属出题 → 复习卷导出
- 【工程】语境是文本不是 id：出题时把 JD 解成文本（岗位 + 技术栈含等级 + 原文截断 1200 字）进 prompt——只传 `jd_analysis_id` 等于没传，曾差点做成挂外键的假功能
- 【工程】图片 OCR 走独立端点 + 10MB 上限，复用同一分析管线

## 4. 技能库（内容最重的板块）

- 【产品】数据诚实：熟练度「未表态 = 未验证」，拒绝 0/50 默认值伪造自评；JD 导入技能不打假分
- 【产品】备注必填：备注是 AI 出题时该技能**唯一**的语境——歧义技能名（如 `harness`）没有备注会被联想成别的技术
- 【产品】知识图谱 + 学习计划：AI 生成一次严格树（≤3 层、顶层 4-6 个、服务端发号 `1 / 1.2 / 1.2.3`）；学习计划 = 图谱切成学习单元，每单元带 `node_ids`
- 【产品】拒绝「重新生成图谱」按钮：节点 id 是分数落点与笔记归属的稳定锚，重生成会让历史数据静默错位——数据一致性优先于操作便利
- 【产品/工程】笔记归属键从易变步骤号改为图谱节点 id（`"4,5"` 合并单元 / `"2"` 单节点）；浏览器老笔记自动认领上收服务端
- 【工程】分数不落库：GET 时纯函数从答题记录现算（叶=证据平均 / 父=子树平均 / 跨来源取最深不平均），从根上消灭缓存脏数据；未测 = null 不参与平均
- 【产品】状态胶囊四态（未生成图谱 / 大部分未测 / 有缺口 / 状态可信）+ 覆盖率条，数字全部来自服务端一份聚合来源（`graph_summary`），前端不另算
- 【UI】分数地图：缩进树五档底色、未测虚线双编码（未测 ≠ 0 分）、分数/覆盖率双视图切换、点节点联动「这一分怎么算出来的」
- 【产品】问一问：每个学习单元一条 AI 对话，开场读笔记做点评 + 指不足，之后自由追问；不判分、不落库，降低用户心理负担
- 【UI】划词高亮 + 浮层笔记，localStorage 持久化，复习快速定位要点

## 5. 面试题库

- 【产品】刷题 / 考试双模式：考试固定 10 单选 + 5 多选 + 3 问答，45 分钟倒计时到时自动交卷
- 【工程】两种判分路线：选择题代码直接比对（确定性），问答题 AI 评分 + 评语 + 参考答案（generator 与 grader 分离）
- 【产品】关联 JD 出题 + JD 详情反查「JD 专属题」；单元级出题挂图谱节点（`node_id`）——分数落回图谱的挂点
- 【工程】技能语境只取备注、不带自由分类（`category` 实测 12 条里 5 条是错误默认值，当判据会把 AI 带偏）
- 【产品】PDF 导出覆盖 5 个场景：刷题页 / 考试页两份考前空白卷、考后含答案卷、技能复习卷、JD 复习卷

## 6. 模拟面试

- 【产品】AI 面试官按目标岗位 + JD 上下文出题追问，逐题实时评分 X/10 + 评语
- 【产品】难度自适应升降级（根据作答质量动态调整追问深度）
- 【产品】语音作答（浏览器 SpeechRecognition），支持 4 种面试类型 × 3 档难度
- 【工程】SSE 流式作答、结束生成综合评价总览

## 7. 岗位推荐

- 【产品】DeepSeek 联网搜索**真实**岗位（不是模型编的），按简历画像刷新
- 【UI】首页流动卡片（marquee 悬停暂停）、详情弹窗一键匹配分析 + 查看原帖
- 【工程】缓存 + 过期判断，避免重复联网调用

## 8. 费曼教学 · 数字学生

- 【产品】反向学习范式：用户给 AI 讲课，AI 批判式听讲
- 【产品】五级理解状态机（混沌/字面/关联/重构/辩证），等级有界升降（+1/-1 禁跳级）
- 【产品】等级 = 知识点覆盖度：讲对新的知识点才升级、覆盖没涨等级原地不动，根治「每说一句就升一级」的伪进步；顶部 ✓/○ 覆盖进度条给真实正反馈
- 【产品】讲错自动降级 + 温和纠正（correction 动作）；追问有预算控制（L3 广度 ×2、L5 深度 ×2）
- 【产品】问题跟踪：手动记录卡点，AI 讲含糊只在回复里提示、绝不自动建项；某轮零卡点自动解决未解决项（非破坏式可重开）
- 【产品】PPT 学习报告（python-pptx），薄弱点累计进报告
- 【工程】多房间状态隔离（`Record<roomId, RoomState>`），并发流式互不串扰

## 9. 横切 · 多 Agent 评审

- 【工程】Evaluator-Optimizer 模式：教学内容先经「资深讲师」（质量）+「模拟用户」（适配度）双 Agent 独立评审，反馈增量注入重新生成（棘轮回滚，上下文不丢）
- 【工程】评审只出 JSON 反馈、绝不自己生成；无 key / 解析失败一律放行（fail-open）

## 10. 横切 · AI 审计与防注入

- 【工程】单点补丁包装 SDK 调用（幂等），不动调用方一行代码覆盖全部 10+ AI 场景；审计落盘 RotatingFileHandler（5MB × 3）
- 【工程】两级防注入：L1 指令/数据分离 + `<user_input>` 定界符；L2 注入模式正则检测，命中标记
- 【工程】流式 token 用量取最后 chunk、取不到按 4 字符/token 估算；耗时单位错乘 1000 的 bug 用单位断言钉死

## 11. 横切 · 测试与质量

- 【工程】TDD，232 个自动化测试（pytest 145 + Vitest 77 + Playwright E2E 10）
- 【工程】测试可信度：修正 E2E「假通过」（`not.toBeVisible()` 在元素 detach 瞬间即通过、在途 DELETE 被掐断，揪出 3 条数据泄漏）→ 等待响应 + 204 断言；修「断言与 React 渲染抢跑」（stale closure 导致请求没发）
- 【工程】疑难缺陷根因治理：React 组件身份缺陷（内联组件 → 每轮重渲染整页卸载重挂 →「一打字整页闪」，修复 + `isConnected` E2E 防回归）
- 【工程】12 个静默失败专项：不报错但结果全错的缺陷逐条修复 + 回归用例

## 12. 横切 · 部署

- 【工程】Docker Compose 编排前后端一键启动；前端多阶段构建（Node 20 → Nginx alpine）+ 静态托管 + API 反向代理
